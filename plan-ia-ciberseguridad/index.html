👋 Cómo usar este plan

¡Bienvenido, Eli! Este plan está pensado para alguien que empieza de cero. No necesitas saber nada antes; cada semana se apoya en la anterior.

  • Con 10 h/semana: haz las tareas principales y el mini proyecto. Con 20 h: repite ejercicios, haz los opcionales y adelanta.
  • Divide en sesiones: por ejemplo, 1.5–2 h de lunes a viernes + un bloque más largo el fin de semana para el mini proyecto.
  • Aprende haciendo: por cada hora de video, al menos una hora escribiendo código. Si te atoras más de 30 min, busca, pregunta y sigue.
  • Marca las casillas conforme avances: se guardan en este navegador (en tu celular o computadora).
  • Si una semana te toma más tiempo, está bien. Lo importante es la constancia, no la velocidad.

⚖️ Ética y legalidad (léelo primero)

Regla de oro: solo practica hacking en sistemas tuyos (tu laboratorio, tus máquinas virtuales) o en plataformas que te dan permiso explícito (TryHackMe, Hack The Box, OverTheWire, PortSwigger, picoCTF, programas de bug bounty con reglas publicadas).

Escanear, entrar o probar ataques en sistemas ajenos sin autorización es un delito en México y en casi todo el mundo, aunque “solo sea para aprender”. Un hacker ético se distingue por tener permiso, respetar el alcance y reportar lo que encuentra de forma responsable.

📅 Semanas 1–12 (detalladas)

S1Fundamentos Cómo funciona una computadora + preparar tu equipo · 10–14 h

🎯 Objetivo: Entender qué hacen el procesador, la memoria y el sistema operativo, y dejar lista tu computadora para programar.

S2Fundamentos La terminal de Linux sin miedo · 10–15 h

🎯 Objetivo: Moverte con soltura en la terminal, leer y buscar en archivos, y entender permisos.

S3Web Git, GitHub y tu primera página web en internet · 10–15 h

🎯 Objetivo: Guardar tu trabajo con Git, subirlo a GitHub y publicar una página HTML gratis.

S4Python Python 1: tus primeros programas · 10–15 h

🎯 Objetivo: Entender variables, tipos de datos, entrada/salida y decisiones (if/else).

S5Python Python 2: ciclos, funciones y listas · 10–15 h

🎯 Objetivo: Repetir tareas con for/while, organizar código en funciones y trabajar con listas.

S6Web CSS: que tu página se vea pro · 10–15 h

🎯 Objetivo: Dar estilo con CSS: colores, tipografía, cajas, Flexbox, Grid y diseño para celular.

S7Python Python 3: diccionarios, archivos y módulos · 10–15 h

🎯 Objetivo: Guardar datos en archivos, usar diccionarios y manejar errores.

S8Web JavaScript: páginas interactivas · 10–15 h

🎯 Objetivo: Variables, funciones y eventos en JavaScript; modificar la página (DOM).

S9Web Tailwind CSS + portafolio publicado · 10–15 h

🎯 Objetivo: Usar Tailwind para diseñar rápido y publicar en Netlify o Cloudflare Pages.

S10Python Python 4: automatizar y usar internet · 10–15 h

🎯 Objetivo: Instalar librerías con pip, usar entornos virtuales y consumir APIs.

S11Redes Redes 1: cómo viaja la información · 10–15 h

🎯 Objetivo: Entender IP, puertos, DNS, HTTP/HTTPS y el modelo TCP/IP.

S12Redes Redes 2: ver el tráfico + repaso general · 10–15 h

🎯 Objetivo: Capturar y entender paquetes con Wireshark; consolidar todo lo aprendido.
